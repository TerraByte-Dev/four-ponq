# Four Ponq

A circular four-player Pong experiment built with Phaser, TypeScript, and Vite.

## Run Locally

```bash
npm install
npm run dev
```

Open the local Vite URL in a browser.

## Controls

- `A` / `D`: move P1 counterclockwise / clockwise
- `Space`: charged catch when P1 charge is full
- `Esc`: open the arcade HOME menu (pauses the game)
- `B`: toggle bot fill
- `R`: reset match
